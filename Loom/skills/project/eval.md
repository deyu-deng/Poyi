## Should trigger
- 建个项目 / 新建一个工程 / 初始化项目目录
- 开始做 XX 项目，帮我建好结构
- 我要开个新坑
- 项目状态 / 我的项目现在到哪了（/project status）
- 更新一下 XX 项目进度（/project update）
- 把 XX 项目归档 / 暂停 / 关闭（/project archive / pause / close）
- /project new | plan | status | update | open | close | pause | block | archive

## Should not trigger
- 今天有什么热点（daily）
- 把散落文件分拣到对应目录（triage）
- 查知识库里项目的资料（query / wiki）
- 帮我写个项目文档模板（交给 notes / ingest）
- 整理课程笔记（notes）
