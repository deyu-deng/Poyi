# 双轨制笔记整理工作流

## 核心理念

解绑"概念理解"与"考场得分"，用不同框架应对：

- **第一轨（知识骨架）**：解决 What / Why —— 严谨、递进、结构化，建立底层逻辑框架
- **第二轨（解题技巧）**：解决 How / When —— 极度功利、If-Then 条件反射，建立肌肉记忆

---

## 七个关键决策

| 问题 | 最终选择 | 具体做法 |
| :--- | :--- | :--- |
| **1. 两轨之间的桥怎么搭？** | **硬链接** | 轨道二的触发器节点直接链接到轨道一的边界条件节点。幕布支持跳转，点击即达。 |
| **2. 轨道一如何避免变废墟？** | **只读 + 错题反向注入** | 轨道一 AI 生成后锁定不动。仅在轨道二刷题踩坑时，回溯到轨道一对应概念并贴链接。不主动维护。 |
| **3. If-Then 如何防反套路崩？** | **极简先验后缀 + 错题反例链接** | 每个触发器下加一句话前提（如"前提：极限不为 1"）。个人踩过的坑挂 `❌` 链接指向错题。 |
| **4. 树状 OPML vs 网状知识？** | **单主链 + 链接旁路** | 每个概念在轨道一中只出现一次，放在最自然的父节点下。其他引用处只放纯文本链接，不展开。保证可分享性。 |
| **5. 视觉锚点是否执行？** | **直接塞图** | 信任幕布的图格式调整足够简单，不成为摩擦。遇到好图直接拍照插入。 |
| **6. 两轨的元决策疲劳？** | **场景硬绑定** | 刷题时**只开轨道二**，复盘/预习时**只开轨道一**。绝不混用，不切换。 |
| **7. AI 骨架是否贴合个人认知？** | **多版本对比选优** | 同一章让 AI 用 3 种逻辑生成骨架（教材原序版 / 应用场景版 / 难度梯度版），30 分钟内选定一版，之后锁定只读。 |

---

## 第一轨：知识骨架

**目标**：对抗遗忘，建立底层逻辑框架。

**内容**：
- 核心定义与定理
- 逻辑推导链条
- 历史背景与直观意义
- 与前文章节的联系
- 辅助理解例题（每个核心概念1道，典型且有一定难度，只写思路不写计算）

**使用场景**：初次预习、章节复盘、底层逻辑模糊时查阅。

**维护方式**：AI 生成后**只读锁定**，不主动编辑。仅在第二轨刷题踩坑时，回溯到对应概念并贴链接。

### 骨架生成流程

1. 向 AI 发送 Prompt，要求生成 3 个版本（教材原序版 / 应用场景版 / 难度梯度版）
2. 30 分钟内选定一版
3. 粘贴为 Markdown，锁定只读
4. 超时强制接受第一版

### 骨架格式规范

```markdown
# 第N章 [标题]

## [N].[M] [小节标题]

### [概念/定理名称]

**定义/定理**：[核心表述，公式用 $...$]

**直观意义**：[一句话解释]

**条件/前提**：[关键条件]

**推导思路**：
- [步骤1]
- [步骤2]

**与前文的联系**：[依赖关系]

#### 典型示例（辅助理解）

**示例**：[一道能体现定理核心特征的典型题，不是简单套公式]

**思路**（不写完整计算）：
- 识别：这是什么类型的问题
- 方法：对应哪个定理/公式
- 验证：结果应该满足什么特征（量纲、符号、边界情况）

> 完整计算见教材/习题册
```

## 第二轨：解题技巧

**目标**：对抗"流利度错觉"，建立肌肉记忆。

**内容**：
- 特征触发器（If-Then）
- 视觉锚点（图像）
- 反例与陷阱 `#陷阱` `#反例`
- 跨章节连结

**使用场景**：考前冲刺、高强度刷题。

**维护方式**：可写，持续补充错题与陷阱。

### 技巧补充流程

1. 刷题时只开第二轨
2. 卡壳/做错 → 15 分钟内写 If-Then 节点
3. 加极简前提条件
4. 必要时链接第一轨对应概念
5. 拍照存错题（命名：`错题-[日期]-[简述].jpg`）

### 技巧格式规范

```markdown
# 第N章 [标题] - 解题技巧

## 题型一：[描述]

If **[特征触发器]** → Then **[操作]**
- 前提：**[极简先验]**
- 链接骨架：[骨架文件路径#锚点]

### 分支A
If **[子特征]** → Then **[操作]**
- 前提：**[极简先验]**
- 触发示例：[一句话描述这类题的典型特征，不是完整题目]
- `#陷阱` [常见错误]
- `❌` [错题链接]

## 跨章节连结
- [技巧] 需要调用 [第X章]

## 陷阱清单
- [ ] `#陷阱` [描述]
- [ ] `#反例` [描述]
```

## 最小可执行工作流

1. **预习/章节初学**：打开轨道一（只读），快速扫 AI 生成的骨架逻辑。
2. **刷题时**：只开轨道二。看到新特征/踩坑 → 写 If-Then 节点，加极简前提，必要时链接轨道一。
3. **考前**：扫一遍轨道二的 `❌` 反例链接和 `#陷阱` 标签。
4. **绝不做的动作**：调整轨道一的层级、为轨道二的图对齐花时间、在两轨之间来回切换比对格式。

## 整合工具：/note-merge

当 NotebookLM 输出或零散片段需要整理时，使用 `/note-merge` skill。

**处理规则**：
- 合并多片段、去重、补全逻辑链条
- 统一标题层级（严格递减，禁止跳级）
- `$$...$$` 块级公式 → `$...$` 行内公式（幕布兼容）
- 表格 → 列表（幕布对表格支持不佳）
- 保留 `#陷阱`、`#反例`、`❌`、`🖼️` 等特殊标记

**使用方式**：
1. 在 Claude Code 中输入 `/note-merge`
2. 粘贴 NotebookLM 输出或笔记片段
3. 说明要整合到**哪一轨**（skill 会自动调整输出风格）
4. 获得可直接贴入幕布的 Markdown 大纲

---

## 幕布导入格式铁律

| 元素 | 幕布兼容性 | 处理方式 |
|:---|:---|:---|
| `#` / `##` / `###` 标题 | ✅ 支持 | 大纲节点 |
| `-` 列表 | ✅ 支持 | 子节点 |
| `$...$` 行内公式 | ✅ 支持 | 保持不变 |
| `$$...$$` 块级公式 | ❌ **不支持** | 转为 `$...$` |
| 表格 | ⚠️ 有限支持 | 转为列表描述 |
| 图片 | ✅ 支持 | 直接粘贴或 `🖼️` 占位 |

**Markdown + LaTeX 格式规范**：

- **文件格式**：Markdown（`.md`），大纲结构用 `#` / `*` / 缩进表示层级
- **数学公式**：用 `$` 包裹 LaTeX，**禁止用 `$$...$$`**
- **大小于号**：幕布对 `<` `>` 兼容良好，可直接书写
- **存量 OPML**：保持不动，需要时重新生成 Markdown 版替换

## 场景硬绑定

- **刷题时**：只开第二轨，绝不看第一轨
- **复盘/预习时**：只开第一轨，绝不写技巧
- **整合时**：明确告诉 `/note-merge` 目标轨道

如果刷题时频繁切到第一轨查概念，说明第二轨的 If-Then 缺前提，或理解没到位。此时应回退到"时间盒切割"（给两轨分配固定时段），而非继续混用。

## 命名规范

| 类型 | 格式 |
|:---|:---|
| 知识骨架 | `CH[NN].md` 或 `骨架-第[NN]章-[主题].md` |
| 解题技巧 | `Calculus.md` 或 `技巧-第[NN]章-[主题].md` |
| 总览/汇总 | `SUMMARY.md` 或 `[学科]-总览.md` |
| 错题照片 | `错题-[日期]-[简述].jpg` |

## 风险控制

| 信号 | 含义 | 应对 |
|:---|:---|:---|
| 刷题时频繁打开骨架查概念 | 技巧缺前提，理解不到位 | 固定每天30分钟只看骨架 |
| 锁定后仍想"再调一调" | 格式完美主义复发 | 强制接受当前版本，30天内不许修改 |
| 技巧文件出现大量 `🖼️` 占位符 | 塞图动作链断裂 | 降级为纯文字视觉化 |
| 同一陷阱反复错 | If-Then 过于笼统 | 拆分为更细粒度的触发器 |

### 隐藏风险点（需自我监控）

1. **场景硬绑定失效信号**：如果你发现自己刷题时频繁切到轨道一"查概念"，说明轨道二的 If-Then 缺前提，或理解没到位。此时应回退到"时间盒切割"（给两轨分配固定时段），而非继续混用。

2. **多版本对比滑入格式深渊**：如果 30 分钟内无法选定骨架版本，或选定后仍想"再调一调层级"，说明格式完美主义复发。应立即放弃对比，直接接受第一版 AI 输出。

3. **视觉锚点堆积不整理**：如果连续一周刷题后，轨道二出现大量 `🖼️` 占位符但无图，说明塞图的动作链已断。此时应降级为"纯文字视觉化"（用文字描述区域形状），不再插入图像。
