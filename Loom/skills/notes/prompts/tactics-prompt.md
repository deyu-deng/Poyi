# 解题技巧生成提示词

将以下内容整理为一份**解题/应用技巧决策树**。

## 角色

竞赛教练。擅长把解题或应用过程提炼成肌肉记忆。目标不是讲概念，而是让读者看到题目/场景特征时，0.5 秒内触发对应操作。

**风格要求**：简洁直接，信息密度高。每个技巧必须能回答："**我看到什么信号时，就知道该用什么方法？**"

## 输入材料

[在此处粘贴你的教材章节、习题解析、实验报告、或错题整理]

## 输出要求

### 1. 标题层级（严禁跳级）

```
# 第N章 [标题] - 解题技巧         # 章级
## 场景X：[描述]                   # 场景级
### 分支A：[子情况]                # 分支级
#### [细节标签]                    # 细节级（陷阱、反例等）
```

### 2. 每个技巧节点必须包含

```
## 场景X：[一句话描述这类题/场景的共同特征]

If **[我在题目/场景中看到了什么]** → Then **[我的第一步操作是什么]**
- 前提：**[极简先验条件，不满足就不能用这个方法]**
- 触发示例：[一句话描述这类题的典型特征——什么信号触发这个操作]
- 链接骨架：[对应的知识概念，如"见第X章 XXX"]

### 分支A：[子情况1]
If **[子特征]** → Then **[子操作]**
- `#陷阱` [这个分支里最常见的错误]
- `#反例` [什么情况下这个方法会失效]

### 分支B：[子情况2]
If **[子特征]** → Then **[子操作]**
```

### 3. 技巧组织原则

- 按**应用场景**组织，不是按教材章节顺序
- 同一类触发器只出现一次，不同变体放在同一个父节点下
- 每个 If-Then 必须包含**前提条件**，防止反套路崩溃
- 每个 `#陷阱` 必须附带一句话说明"**为什么会这样想错**"

### 4. 章末必备

- **跨章节依赖清单**：列出本章所有技巧依赖的前面知识
- **陷阱清单**：汇总本章所有 `#陷阱` 标签

### 5. 视觉锚点

- 如果某类题型/场景有强烈的视觉特征（如图像形状、公式结构、实验装置），用文字描述这个视觉特征
- 用 `🖼️` 标记需要配图的位置（后续拍照替换）

### 6. 格式

- Markdown 大纲，层级用 `#` / `##` / `###` / `-`
- **所有公式用单行 `$...$` 包裹，不要用 `$$...$$`**
- 用 `If [特征] → Then [操作]` 的句式组织核心节点

### 7. 控制（禁止输出）

- 概念定义（那是第一轨的事）
- 完整解题过程（只输出决策节点）
- "灵活运用""视情况而定"等模糊表述（必须给出明确的 If 条件）
- 遗漏反例和失效条件（这是防反套路的核心）
