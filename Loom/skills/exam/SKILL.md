# 公众号历年试卷收集与排版 Skill

## 概述

从微信公众号（如"路老师的nonsense collection"）收集历年试卷，OCR 提取题目，AI 自行解答，生成统一排版的 LaTeX PDF 文档。

## 适用场景

- 目标内容在微信公众号文章中，无法通过 API 直接获取
- 试卷以图片形式嵌入文章，需要 OCR 或截图提取
- 需要将散落的试卷整理为统一格式的 PDF（题目在前，答案在后）

## 完整流程

### 第一步：获取文章列表

**方法A — 搜狗微信搜索（推荐首选）**

```
https://weixin.sogou.com/weixin?type=2&query=<关键词>
```

- 逐页抓取（page=1,2,3...），提取文章标题和摘要
- 确认目标公众号名称（注意用户可能用简称，需匹配全称）
- 筛选出目标类型的文章（如"微积分甲II 期末"）

**方法B — 浏览器直接浏览公众号文章列表**

如果搜狗搜索未索引最新文章，派发 `browser` agent 通过搜狗微信搜索进入公众号文章列表页浏览。

**方法C — Google/Bing 搜索**

```
site:mp.weixin.qq.com "公众号名称" 关键词
```

### 第二步：截图收集

派发 `browser`：
- 在搜狗微信搜索结果中逐篇打开文章
- 对每篇文章截图保存（题目和答案分别截图）
- 优先处理核心真题（期末 > 期中 > 模拟题），按年份从新到旧
- 截图保存到 output 目录，命名格式：`序号_年份_类型_描述.png`

### 第三步：确定目标文件夹

派发 `file-agent`：
- 搜索用户 Cloud/Courses 目录下的课程文件夹结构
- 确认历年卷应存放的路径
- 创建目标文件夹（如 `历年卷/`）

### 第四步：整理分类截图

派发 `file-agent`：
- 按课程（甲I/甲II）将截图分类到对应文件夹
- 统一重命名格式：`20XX-20XX学年_期中/期末_题目/答案.png`
- 修复序号冲突和重复问题

### 第五步：题目提取

**方案A — analyze_image 提取（优先用于印刷体试卷）**

```
analyze_image(file_paths=[...], prompt="逐题提取所有题目内容，保持数学公式完整。按题号列出。")
```

**方案B — file-agent OCR 提取**

派发 `file-agent` 对截图进行 OCR 识别。

**方案C — 手写笔记处理**

对于手写笔记（OCR 难以识别），用 `analyze_image` 逐张分析，prompt 中明确要求"只提取题目，不含答案"。

### 第六步：AI 解答 + 生成 PDF

派发 `file-agent`（复用同一 agent_id 保持上下文）：

```
Task: 根据以下题目写出完整解答，生成 PDF
- 题目在前，答案在后
- LaTeX 排版，数学公式使用 LaTeX 格式
- 统一字体和排版风格
- 保存到对应历年卷文件夹
```

**注意事项**：
- 每批处理 2~3 题，避免内容过长导致连接超时
- 复杂试卷（12题+）拆分为多个 PDF 分批处理
- OCR 可能有误差，在 task 中注明"请根据微积分知识合理推断修正"

### 第七步：补漏

- 截图质量问题 → 重新派发 `browser` agent 截图
- 手写答案无题目 → 用 `analyze_image` 提取题目，自行解答
- 搜索结果遗漏 → 换关键词重新搜索

## 关键原则

1. **AI 自行解答优于 OCR 手写答案**：手写答案 OCR 几乎必然失败，直接让 AI 根据题目自行解答效果远超 OCR
2. **逐级降级**：app-agent → browser → web_fetch/web_search，哪个能获取内容就用哪个
3. **分批处理**：PDF 生成每批不超过 3 题，避免超时
4. **复用 agent_id**：同一类任务使用 `inherit_agent_id` 保持上下文，提高效率
> Hermes-era 概念，Marvis 等效为 dispatch_task 的 inherit_agent_id 参数。
5. **搜狗优先**：搜狗微信搜索是获取公众号文章最稳定的公开渠道，优先于 Google/Bing

## 常见坑

| 问题 | 解决方案 |
|------|---------|
| 微信不在自动化列表 | 改用搜狗微信搜索 |
| 搜狗未索引最新文章 | 用 browser agent 浏览公众号文章列表 |
| 手写答案 OCR 失败 | 提取题目后 AI 自行解答 |
| 截图不完整/占位图 | 重新截图 |
| LaTeX 编译超时 | 拆分为每 2-3 题一个 PDF |
| 用户用公众号简称 | 搜索时尝试全称和简称 |
| 缺少目标年份 | 确认公众号是否已发布，关注后续更新 |

## 产出物标准

- PDF 格式，LaTeX 排版
- 前半部分：题目（题号 + 完整题目内容）
- 后半部分：详细解答（步骤 + 最终答案）
- 统一命名：`20XX-20XX学年_期中/期末.pdf`
- 存放路径：`D:/Cloud/Courses/<课程文件夹>/历年卷/`
*（内容由AI生成，仅供参考）*
