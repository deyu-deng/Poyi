# Hash Table Key-Value 键值对

## 核心定义

哈希表（字典）本质是一张**查表**：给一个**键（key）**，返回一个**值（value）**。

> 键 = 你问的问题，值 = 答案。

生活类比：手机通讯录按"名字"（键）查"号码"（值）；英汉字典按"单词"（键）查"释义"（值）。

## 三条硬规则

1. **键必须唯一**：同一键重复赋值 = 覆盖旧值，不会新增条目。
2. **值可以随意变**：值只是被查询的结果，可增可减可覆盖。
3. **查不存在的键是分叉点**：Python 直接报 `KeyError`，C++ 自动插入默认值 0——这是两语言最易踩的坑。

## Python dict vs C++ unordered_map

| 维度 | Python `dict` | C++ `unordered_map` |
|---|---|---|
| 声明 | `cnt = {}` | `unordered_map<int, int> cnt;` |
| 取值 | `cnt[x]`（键不存在报错） | `cnt[x]`（键不存在自动插入默认 0） |
| 安全取值 | `cnt.get(x, 0)`（不存在返回 0） | 无需求，`[]` 自带兜底 |
| 计数加一 | `cnt[x] = cnt.get(x, 0) + 1` | `++cnt[x]` |
| 删除/减一 | `cnt[y] -= 1`（先确认存在） | `--cnt[y]` |

**记忆锚点**：Python 需要 `get` 兜底，C++ 的 `[]` 自带兜底；C++ 的 `++cnt[x]` 等价于 Python 三行合写。

## 典型用途

- 统计频率（元素 → 出现次数）
- 缓存 / 查表（输入 → 输出）
- 去重（键唯一性）
- 配合 [[Sliding-Window]] 维护窗口内元素计数
