# 量化交易-入门

## 概述

小满（北屿大学机电工程，学生，可投入资金几千元）计划学习炒股与量化交易。量化交易通过数学模型和代码替代主观判断，本质是"用脑力+纪律+资本"一起赚钱。当前阶段以学习原理、模拟练手为主，不急于实盘。

## 核心概念

### 期望收益公式

**期望收益 = 胜率 × 平均盈利 - 败率 × 平均亏损**

所有策略设计的落脚点：抬高胜率、拉大盈亏比、控制亏损。不需要每笔都赚，只要期望为正即可长期盈利。

### 策略六环节骨架

| 环节 | 作用 |
|------|------|
| 选股/选品种 | 从候选池筛选 |
| 入场信号 | 何时买入 |
| 仓位管理 | 买多少 |
| 止损 | 亏多少认栽 |
| 止盈/出场 | 何时卖出 |
| 风控总闸 | 整体上限 |

任何一环没想清楚就实盘，大概率亏损。

### 回测关键指标

- **夏普比率**：每单位风险的超额收益，>1 及格，>2 优秀
- **最大回撤**：峰值到谷底最大跌幅，>20% 普通人扛不住
- **胜率**：>40% 配合 3:1 盈亏比即可赚钱
- **过拟合**：参数过度匹配历史数据、对未来无预测力——回测收益越高越要怀疑

### 策略类型

趋势跟踪 / 均值回归 / 因子选股 / 统计套利 / 高频交易（个人不碰）

## 主要坑点

- 过拟合（回测曲线美如画，实盘亏成狗）
- 幸存者偏差（回测剔除了退市股）
- 交易成本（滑点、佣金、印花税吃掉超额收益）
- 未来函数（用了未来数据）

## 与股票分析的关系

投资分析不等于量化。看数据、画图、对比是投研分析（主观判断）；量化是定义规则后让机器自动执行。分析是量化的前置工作。
