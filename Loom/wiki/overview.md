# Wiki Overview — 知识图谱概览

## Poyi 系统整体架构

Poyi 是小满的第二大脑，一个三层结构的知识管理系统。它的设计哲学是"知识复利"——每次吞入一份资料，每次回答一个问题，知识库就变得更加丰富和有价值。

```
/Users/sample/Poyi/
├── Loom/          ← AI 织机工作区（本目录）
│   ├── raw/       ← 第一层：原始资料，拖入即忘
│   ├── wiki/      ← 第二层：AI 生成的知识库
│   └── output/    ← 第三层：衍生输出
└── Vault/         ← 人工笔记工作区
```

## Loom 织机工作区

Loom 是 Poyi 的 AI 部分。命名来源于织机（loom）的隐喻——将分散的线（原始资料）编织成有结构的织物（知识库）。

### 三层架构的意义

**第一层 raw/ — 原始资料**：信息入口。文章、论文、片段、对话记录。这一层是"拖入框"——把任何想了解的东西放进来。永远不修改原始文件，保持溯源的完整性。

**第二层 wiki/ — 知识库**：AI 的持久化产出。从 raw/ 中提取实体和概念，建立交叉引用，标注矛盾，综合不同来源的信息。这是知识复利发生的地方。格式化为 Obsidian wiki，支持图视图、双向链接、Dataview 查询。

**第三层 output/ — 衍生输出**：面向外部的产物。研究报告、演示文稿、分析文档——从 wiki 中导出，而非从头编写。wiki 是单一真相来源，output 是它的不同呈现形式。

## 核心流程

```
[raw/ 源文件]  →  [Ingest]  →  [wiki/ 结构化页面]
                                       ↓
                                  [Query]  ←  用户提问
                                       ↓
                                  [wiki/ 综合答案]
                                       ↓
                           [output/ 报告/幻灯片]
```
