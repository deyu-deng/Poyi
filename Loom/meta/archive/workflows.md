# Workflows — 工作流

## 日常笔记

1. 打开 Obsidian（Vault vault）
2. 新建日记：`journal/YYYY-MM-DD.md`
3. 学科笔记放入对应学科目录（如 `数学 Math/`）
4. 项目笔记放入 `projects/<项目名>/`

## AI 知识编译

1. 把资料拖入 `Loom/raw/`
2. 在 Claude Code 中运行 `/ingest <文件>`
3. AI 自动编译到 `Loom/wiki/`

## 同步

- Poyi 目录是一个 Git 仓库，定期 `git push`
- .obsidian/ 配置不同设备独立，不跟踪

## 目录规范

- 学科目录：`中文 English` 格式（≤2 词）
- 项目目录：`kebab-case` 格式
- 禁止在根目录散落文件
