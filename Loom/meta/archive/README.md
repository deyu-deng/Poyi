# Loom/meta/archive/ — 历史归档

> **本目录不是事实来源。**
> 这里存放的是历史快照与已被取代的文档。阅读 Poyi 当前结构，请以 `AGENTS.md` + `Loom/skills/INDEX.md` + `propagation-map.md` 为准。
> 本目录下的报告**不要**作为当前状态的依据。

---

## 为什么归档

这些文件是 2026-06-30 ~ 2026-07-02 期间，在不同机器（Windows / macOS）上由不同 Agent 生成的审计 / 修复报告。
它们被 git 合并后**从未对齐**，彼此在健康度评分、目录是否存在、SOUL.md 处置等问题上**互相矛盾**，且大量"已文件系统验证"的声明在当前 macOS 磁盘上不成立（例如声称 `.beacon`、`.UTSystemConfig`、顶层 `.claude` 存在，但 Mac 上均不存在——那是 Windows 侧的状态）。

2026-07-09 整理时，将它们从 `Loom/meta/` 顶层移入本目录，仅作历史追溯，**不删**。
